# Forster Kwarteng Foundation (FKF)

> *"Empowering Lives, Building Futures"*

Official website repository for the **FORSTER KWARTENG FOUNDATION**, a non-profit organization based in Accra, Ghana, established to empower individuals and communities through education, mentorship, skills development, and sustainable social interventions.

---

## 🌟 The 4 Core Pillars

1. **Pillar 01 • Educational Sponsorship**: Equipping orphaned and vulnerable school children with textbooks, uniforms, learning kits, and scholarships.
2. **Pillar 02 • Girl-Child Literacy & Mentorship**: Providing safe reading clubs, structured mentorship circles, and life-skills guidance for young girls.
3. **Pillar 03 • Community Care & Relief**: Delivering emergency food packages, back-to-school essentials, and grassroots safety nets to underserved families.
4. **Pillar 04 • Sustainable Futures**: Supporting vocational skill acquisition, youth development, and community-led initiatives for lasting self-reliance.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler & Dev Server**: [Vite 6](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations & Effects**: Motion + Canvas Confetti

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation & Local Development

```bash
# 1. Navigate to the website folder
cd website

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Build for production
npm run build

# 5. Preview production build locally
npm run preview
```
